I have an offset or address

Type it as OllyDbg or x64dbg shows it. An offset inside a function or a table finds the thing that holds it, so the offsets from the forum and from patch lists work too.

008E7810 0x8e7840 0xae2c90

Some offsets are positions in the exe file, the kind you add 0x400000 to for Olly. Tick "File offset" and the page adds it for you.

How sure is a name?

high
A string, an assert, a caller or a vtable slot pins the purpose.
medium
The shape of the code and its callers agree, but no single fact proves the name. Read the code first.
low
A guess.
Medium and low names are hints: read the code before you rely on them. The map holds no code of the original. Report a wrong name. CC BY 4.0. Not affiliated with Sports Interactive, SEGA, Eidos or Square Enix.
